🏗️ League Setup

Type a league title to search TheSportsDB. Selecting a match fills the title and league icon (badge → logo). Trophy and ball URLs can be set separately.

Select at least one stage. Group Stage pots earn W/D/L from group matches; Knockout pots from KO matches. Standings points sum both.

When enabled, each knockout tie has Leg 1 and Leg 2. Winner is decided by the combined score of both legs.

Main Quest

Main Quest points apply to Full Time (90 min) scores only — not Extra Time. Each participant has separate table pots for Group Stage and Knockout Stage; standings combine both.

Set W/D/L per team (based on FIFA ranking strength). Weaker teams can carry higher rewards so supporting underdogs stays fair. Add teams in Section 3 first.

Side Quest

Side Quest points apply after awards are resolved. Enable “Share points equally” to split that category’s points among all correct guessers (e.g. 20 pts ÷ 5 people = 4 each). Total Goal awards the closest prediction(s). Score Predict awards exact full-time score hits per match.

Match Schedule

Set kickoff date and time in 24-hour format (WIB) for each match. Leave date blank if not scheduled yet.

Exact FT score predictions per match. Participants earn Score Predict points only when both sides match the final full-time score. Leave blank if not predicted yet. Use ✕ to clear an accidental prediction.
