🏗️ League Setup

Type a league title to search TheSportsDB. Selecting a match fills the title and league icon (badge → logo). Trophy and ball URLs can be set separately.

When enabled, each knockout tie has Leg 1 and Leg 2. Winner is decided by aggregate score.

Main Quest

Main Quest points apply to Full Time (90 min) scores only — not Extra Time.

Side Quest

Side Quests points apply to Full Time (90 min) and Extra Time scores.

Playoff Schedule

Set kickoff date and time (WIB) for each knockout match. Leave blank if not scheduled yet.
